# Hostiva — Event Management Platform

Hostiva is a modern event management and discovery platform built using **Next.js,Clerk, and Convex**. It helps users discover, create, and manage events through a clean, responsive, and user-friendly interface.

The platform is designed for people who want to explore events across different cities and states, register for events, and manage their tickets in one place.

## Live Demo

Live Project: https://hostiva-puce.vercel.app

## Project Overview

Hostiva allows users to discover and create amazing events. The application includes event browsing, location-based filtering, authentication, event creation, and ticket management features.

Users can search for events, filter them by state and city, explore featured events, view event details, and manage registered events from the My Tickets section.

## Tech Stack

- **Frontend:** Next.js,
- - **Styling:** Tailwind css
- **Authentication:** Clerk
- **Backend / Database:** Convex
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## Features

- Modern landing page with attractive UI
- User authentication using Clerk
- Search events by keyword
- Filter events by state and city
- Explore featured events
- Create new events
- View event cards with date, location, category, and registration count
- My Tickets page to view and manage event registrations
- Responsive and dark-themed user interface
- Clean navigation with Explore, Pricing, Sign In, and Create Event options
- Deployed live using Vercel

## Screens / Pages

### Landing Page
The landing page introduces Hostiva with the tagline:

**Discover & create amazing events.**

It includes a clean hero section, call-to-action button, navigation bar, and search/filter options.

### Explore Events Page
The Explore page allows users to browse featured events across India. Events are shown with image cards, event title, date, location, and registration details.

### Search and Filtering
Users can search for events and filter them by:

- State
- City
- Event keyword

This improves discoverability and helps users find relevant events quickly.

### Create Event
Authenticated users can create events using the platform. This feature is useful for event organizers who want to list their events.

### My Tickets
The My Tickets page allows users to view and manage their event registrations. It shows past events with details like category, date, location, and registration count.
